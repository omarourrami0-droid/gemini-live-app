# محادثة جيميني — تطبيق ويب يُثبَّت على الهاتف

محادثة صوتية مباشرة مع `gemini-3.8-live` (أفضل نموذج Live في اختباراتنا لفهم الدارجة).
بلا خادم وبلا أدوات بناء: `index.html` + `app.js` + بيانات التثبيت.

## الاستعمال
1. افتح الرابط (HTTPS ضروري للميكروفون) من كروم على أندرويد أو سفاري على آيفون.
2. من القائمة اختر «إضافة إلى الشاشة الرئيسية» ليعمل كتطبيق.
3. الإعدادات ⚙ ← الصق مفتاح Gemini API (يُحفظ في الهاتف فقط) ← حفظ.
4. اضغط «ابدأ المحادثة» وتكلّم. يُفضَّل استعمال سماعات.

## التجربة على الحاسوب
```
cd C:\Users\dell\Desktop\Projects\gemini-live-app
python -m http.server 8765
```
ثم افتح `http://localhost:8765` في كروم (الميكروفون يعمل على localhost).

## ملاحظات تقنية
- الاتصال مباشر من المتصفح إلى Gemini Live عبر WebSocket، والمفتاح في `localStorage` ولا يوجد في أي ملف.
- الإرسال: PCM 16kHz من `AudioWorklet`. الاستقبال: PCM 24kHz يُجدوَل بدقة، وعند المقاطعة يُفرَّغ الطابور فوراً.
- لا نضبط `languageCode` عمداً: جعل النموذج يتبع تفريغاً خاطئاً (إسبانية بدل الدارجة).
- النص الظاهر تحت كلامك يأتي من خدمة تفريغ منفصلة وقد يخطئ في الدارجة الرديئة؛ فهم النموذج نفسه أدق منه.
- الجلسة تُستأنف تلقائياً عند انقطاع الاتصال، وسياقها يُضغط تلقائياً لتطول المحادثة.
